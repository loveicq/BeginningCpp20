# 个人学习C++的小屋

1. 使用教材为《C++20入门实践(第6版)》。
2. 操作系统为windows10_x64,编辑器为vscode1.101.2版,编译器为mingw15.1.0。
3. 第11章以后涉及模块，改用vscode + vs2026(利用自带的msvc + cmake + minja) + cmake tools扩展 + .vsocde/settings.json配置编译和调试环境。

   1. 先把CPP20根目录的CMakeLists.tmp文件复制到案例根目录，并改后缀名为txt。
   2. 点击菜单：文件-打开文件夹，选择案例根目录。
   3. 待vscode窗口中间上方弹出“为Exxx-xx选择工具包”的时候，
      选择下拉列表的“Visual Studio Community 2026 Release - amd64”。
   4. 等输出窗口显示“[cmake] -- Build files have been written to: E:/cpp/Gitee/cpp20/Chapter11/Ex11_03/build”，
      即表示完成配置。
   5. 按F7进行编译。
